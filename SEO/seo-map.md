## Цель
Органический трафик по коммерческим запросам в Санкт-Петербурге, Москве и Московской области с приоритетом B2B.

## Перелинковка
Главная → услуги → проекты → статьи.
Каждая статья должна ссылаться на соответствующую услугу, проект и заявку.
Каждый проект должен ссылаться на соответствующую услугу.

## Индексация
Обязательные элементы:
- robots.txt
- sitemap.xml
- canonical на индексируемых страницах
- уникальные title/description
- один H1 на страницу
- HTTP 200 для канонических URL
- корректные 301 для старых URL
- отсутствие внутренних 404
- изображения с alt
- доступность CSS/JS/изображений для роботов

## Контент
Не создавать массовые страницы с одинаковым текстом только ради геозапросов. Региональные страницы создавать только при наличии уникального полезного содержания, объектов, кейсов или условий работы.

## Приоритет работ
P0: индексация и техническая доступность.
P1: внутренняя перелинковка и метаданные.
P1: отдельные страницы СКС, CCTV, СКУД, АПС/СОУЭ.
P2: статьи под информационные запросы и привязка к коммерческим страницам.
P2: расширение кейсов по типам объектов.

## Контроль
После каждого изменения проверять sitemap, robots, HTTP-коды, canonical, внутренние ссылки и ключевые страницы.
