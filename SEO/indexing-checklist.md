# План индексации Group Integra

## P0 — проверить и исправить
- robots.txt доступен по /robots.txt и не блокирует важные страницы.
- sitemap.xml доступен по /sitemap.xml и содержит только канонические URL.
- В sitemap нет 404, 500, редиректов и дублей.
- Главная, /slabotchka.php, /gsm.php, /projects/ и /articles/ доступны роботам.
- Проверить canonical на всех индексируемых страницах.
- Проверить HTTP-коды и внутренние ссылки.
- Не включать в индекс служебные файлы, формы, временные URL и параметры без SEO-ценности.

## P1 — поисковая структура
- Уникальный title и description для каждой целевой страницы.
- Один понятный H1.
- Хлебные крошки там, где структура это оправдывает.
- Ссылки из услуг на проекты и релевантные статьи.
- Ссылки из проектов на соответствующие услуги.
- Ссылки из статей на коммерческие страницы.
- У изображений содержательные alt.

## P2 — расширение семантики
Создавать отдельные страницы только при наличии самостоятельного содержания:
СКС, видеонаблюдение, СКУД, пожарная сигнализация, СОУЭ, Wi-Fi/IT-инфраструктура.

## Региональное SEO
Основные регионы: Санкт-Петербург, Москва, Московская область.
Не создавать десятки одинаковых региональных страниц. Для региона нужна уникальная ценность: реальные проекты, условия работы, адрес/зона обслуживания, особенности объектов.

## Регулярный контроль
После публикации новых страниц проверять:
1. HTTP 200.
2. canonical.
3. попадание в sitemap.
4. внутренние ссылки.
5. доступность ресурсов.
6. отсутствие случайного noindex.
