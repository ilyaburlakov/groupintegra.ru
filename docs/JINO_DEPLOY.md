# Автоматический деплой groupintegra.ru на Jino

Сайт разворачивается из ветки main через GitHub Actions.

## Секреты GitHub

В Settings → Secrets and variables → Actions создайте:

- JINO_HOST — SSH-хост Jino, например `логин.myjino.ru` или домен.
- JINO_USER — логин SSH на Jino.
- JINO_PATH — путь к сайту, обычно `~/domains/groupintegra.ru`.
- JINO_SSH_KEY — приватный SSH-ключ для входа на Jino.
- JINO_KNOWN_HOSTS — строка из `ssh-keyscan` для выбранного SSH-хоста.

Jino указывает SSH-подключение на 22-м порту по умолчанию. Перед использованием SSH услугу нужно подключить и при необходимости разрешить IP доступа. citeturn941419search6

## Серверная конфигурация каталога

Реальные реквизиты БД не хранятся в Git.

На Jino должен существовать файл:

`~/incs/groupintegra-catalog.php`

с константами DB_HOST, DB_NAME, DB_USER, DB_PASS и DB_PORT.

Файл находится вне web-каталога и не перезаписывается автодеплоем.

## Что сохраняется при деплое

Автодеплой не трогает:

- `catalog/uploads/` — загруженные изображения товаров;
- `catalog/includes/config.local.php`;
- `.env`;
- `.well-known/`;
- `logs/`;
- `tmp/`.

Все остальные файлы web-каталога синхронизируются с main, включая удаление устаревших файлов.

## Важно

В репозитории ранее находились реквизиты MySQL. После перехода на новую конфигурацию пароль БД необходимо сменить в панели Jino, потому что старое значение остаётся в истории Git.
